I'm setting up a GitHub Pages instance to use as a portfolio and development blog for my projects and tinkerings. My current ongoing projects are:

* My NixOS fleet managed through [my nix-dendrites config](https://github.com/sabrsorensen/nix-dendrites) based on [Dendritic Nix](https://github.com/mightyiam/dendritic) and the self-gating module broadcast model used in [wimpysworld/nix-config](https://github.com/wimpysworld/nix-config).
* A HawkBit OTA A/B update proof-of-concept using U-boot, swupdate, and Buildroot on a Raspberry Pi 4 and docker-compose and Caddy to host the HawkBit and HawkBit-UI instances.
* Learning STM32 and ESP32 MCUs as part of an ongoing effort to return to embedded systems engineering professionally.
